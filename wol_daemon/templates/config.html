Export

Downloads the complete configuration as a YAML file: machines, clusters, schedules and settings.

It contains Proxmox token secrets in plain text, so store it like a password. SSH private keys are not included, only their paths; copy the key files separately.

Download config

Import

Replaces the entire current configuration with the uploaded file. The file is checked first: if it has any error, nothing changes. The current config.yaml is kept in backups/ before it's overwritten.

WOL_* environment variables are set on this node, so the machine "default" is taken from them again after the import.
